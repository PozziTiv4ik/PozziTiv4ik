RepoTrials mines real fixes from Git history, validates reproducible BASE/RED/GOLD test transitions, runs repeated agent trials, and grades behavior with hidden tests. Source, tasks, and verifier material stay local by default.

- No model API key is needed for the included end-to-end demo.
- Any command-based coding agent can be evaluated.
- Results are written as auditable JSON and HTML reports.
- Accepted tasks can be exported for [Harbor](https://github.com/harbor-framework/harbor).
